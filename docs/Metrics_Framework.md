# 产品评估指标框架 (Metrics Framework)

## 1. 指标框架概述
本框架旨在为“竖式计算练习页生成器”定义一套清晰、可衡量的评估指标，用于跟踪产品表现、衡量产品成功，并为未来的产品迭代提供数据驱动的决策依据。我们将聚焦于反映用户核心价值实现情况的指标。

## 2. 北极星指标 (North Star Metric)
- **指标定义**: **成功打印的练习页数量**
- **选择依据**:
  - **反映核心价值**: 该指标直接度量了用户是否完成了从内容生成到获得最终实体产出（打印页）的整个核心流程。每一次成功的打印都代表着产品为用户创造了一次完整的价值。
  - **驱动团队方向**: 团队的所有工作（无论是优化加载速度、改进排版，还是简化打印流程）都应以提升此指标为最终目标，确保了方向的一致性。
  - **易于理解和衡量**: 指标直观，易于团队所有成员理解，并且可以通过前端事件埋点进行相对准确的追踪。
- **计算公式**: `“打印”按钮点击事件触发次数`
- **目标**: MVP上线后，首月达到1,000次打印。

## 3. AARRR 指标体系详述
考虑到本产品MVP阶段的工具属性和极简特性，我们采用一个简化的AARRR模型来分析用户生命周期。

- **Acquisition (用户获取)**
  - **定义**: 用户如何找到并首次访问我们的产品。
  - **关键指标**:
    - **页面访问量 (Page Views)**: 网站被浏览的总次数。
    - **独立访客数 (Unique Visitors)**: 在特定时间内访问网站的去重用户数。
  - **数据来源**: 网站分析工具（如Google Analytics, Plausible Analytics等）。
  - **目标**: 通过口碑传播，在无推广费用的情况下，首月获得500个独立访客。

- **Activation (用户激活)**
  - **定义**: 用户首次体验到产品“Aha Moment”的时刻。对于本产品，即成功看到自动生成的练习页。
  - **关键指标**:
    - **练习页生成成功率**: `(成功生成页面的会话数 / 总会话数) * 100%`
  - **数据来源**: 前端事件埋点。
  - **目标**: 激活成功率 > 95%。

- **Retention (用户留存)**
  - **定义**: 用户在一段时间后再次回到产品。
  - **关键指标**:
    - **次日/次周回访率**: `(第N天后回访的用户数 / 第一天访问的用户总数) * 100%`
  - **数据来源**: 网站分析工具。
  - **目标**: 作为一个低频工具，我们更关注其在需要时是否被用户想起。初期设定次周回访率 > 10%。

- **Revenue (商业收入)**
  - **定义**: 产品的盈利情况。
  - **关键指标**:
    - **暂不适用**: MVP阶段为免费工具，此项指标为 N/A。

- **Referral (用户推荐)**
  - **定义**: 用户通过口碑等方式自发推荐产品。
  - **关键指标**:
    - **直接访问与社交媒体来源占比**: 分析流量来源中，直接输入网址或来自社交分享的比例。
  - **数据来源**: 网站分析工具。
  - **目标**: 观察直接访问流量占比随时间推移是否稳步增长。

## 4. 功能级评估指标
| 功能模块 | 关键指标 | 描述 |
| :--- | :--- | :--- |
| **题目加载** | **JSON加载成功率** | `(JSON成功加载次数 / 页面总访问次数) * 100%` |
| | **平均加载时间** | 从请求到解析完成的平均耗时。 |
| **页面渲染** | **平均渲染时间** | 从数据就绪到页面完全渲染的平均耗时。 |
| **打印功能** | **打印转化率** | `(打印按钮点击次数 / 页面生成成功次数) * 100%` |

## 5. 指标监测计划
- **工具选择**:
  - **前端埋点**: 使用轻量级的网站分析工具（如Plausible Analytics或自建方案），避免影响页面性能。
  - **数据可视化**: 使用分析工具自带的仪表盘或连接到数据可视化工具（如Metabase, Grafana）。
- **埋点事件列表**:
  - `page_view`: 用户访问页面。
  - `generate_success`: 练习页成功生成并渲染。
  - `generate_fail`: 因数据加载或处理失败导致页面生成失败。
  - `print_click`: 用户点击“打印”按钮。
- **报告与回顾周期**:
  - **周报**: 自动生成关键指标（PV, UV, 打印次数）的周报。
  - **月度回顾**: 每月召开一次数据回顾会议，由产品经理分析用户行为趋势，讨论数据背后的原因，并为下个迭代的规划提供输入。
