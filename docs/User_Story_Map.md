# 用户故事地图 (User Story Map)

## 1. 用户故事地图概述
本用户故事地图旨在可视化“竖式计算练习页生成器”的用户体验流程。它以用户活动为骨干，将用户任务和具体的用户故事进行分解和组织，并映射到不同的产品发布版本中，以确保开发工作始终聚焦于为用户创造最大价值。

**核心用户**: 教师 / 家长

---

## 2. 用户活动流 (Activities - 横向)
| 用户活动 (蓝色) | 准备练习材料 | 生成练习页面 | 获取实体练习卷 | (未来) 管理与扩展 |
| :--- | :--- | :--- | :--- | :--- |

## 3. 用户任务分解 (Tasks & Stories - 纵向)

| **用户活动** | **准备练习材料** | **生成练习页面** | **获取实体练习卷** | **(未来) 管理与扩展** |
| :--- | :--- | :--- | :--- | :--- |
| **用户任务 (绿色)** | **访问工具** | **加载题目** | **预览与检查** | **打印页面** | **获取更多题目** | **使用答案** | **自定义题目** |
| **用户故事 (黄色)** | 作为用户，我希望能直接打开一个网址就开始使用，无需注册登录。 | 作为用户，我希望页面能自动加载预设的题目，无需我手动输入。 | 作为用户，我希望题目能以竖式计算的格式清晰展示，留出计算空间。 | 作为用户，我希望所有题目能自动排版在一个A4大小的页面上，布局为4x5。 | 作为用户，我希望能看到一个清晰的页面预览，就像最终打印出来的一样。 | 作为用户，我希望能有一个“打印”按钮，可以一键调用打印功能。 | 作为用户，我希望打印出来的内容是纯净的练习题，没有网站logo、按钮等无关元素。 | 作为用户，我希望如果题库里有超过20道题，我能翻页查看并生成下一页。 | 作为用户，我希望能有一个选项，可以生成带答案的页面，方便我批改作业。 | 作为用户，我希望能上传自己的题目文件。 |
| | | 作为用户，我希望如果题目加载失败，能看到明确的提示信息。 | | | | | | | | |
| **技术故事 (灰色)** | - | - | 实现一个能根据被除数和除数动态生成竖式框架的组件。 | 使用CSS Grid或Flexbox实现响应式的4x5网格布局。 | - | 使用`window.print()`实现打印功能。 | 使用`@media print` CSS规则来定义打印专用样式。 | 实现分页逻辑，每次从JSON数组中取不同的切片。 | 实现一个切换开关，用于控制是否在页面上渲染答案。 | 实现文件上传和解析功能。 |

## 4. 故事优先级与版本映射

### **Release 1: MVP (v1.0)**
*   **核心目标**: 用户可以成功生成并打印出第一页（20题）的练习卷。
*   **包含的故事**:
    *   **访问工具**: 直接打开网址使用。
    *   **加载题目**: 自动加载预设题目；加载失败提示。
    *   **预览与检查**: 竖式格式展示；A4页面4x5自动排版；清晰的页面预览。
    - **打印页面**: “打印”按钮；打印纯净内容。

---

### **Release 2: 功能增强 (v2.0)**
*   **核心目标**: 提供更多灵活性和便利性。
*   **包含的故事**:
    *   **获取更多题目**: 翻页查看和生成下一页。
    *   **使用答案**: 生成带答案的页面。
    *   **(可选)** **自定义题目**: 上传自己的题目文件。
